# Robot-Control-Center-OOP-Project
    
# Features (bottom)

    System will store robot data, monitor integrated sensors, update operational states, and execute custom commands.

    Uses 4 classes, Sensor class, Robot class, MobleRobot class, and DroneRobot class

    Uses class Sensor that stores 3 atributes (sensor_id, name, sensor_type).

    Uses class Robot that stores 4 attributes (robot_id, name, battery, status).

    Uses class MobileRobot that stores 5 attributes (robot_id, name, battery, status, speed).

    Uses class DroneRobot that stores 5 attributes (robot_id, name, battery, status, max_altitude).
